# EstudoDeCaso-EfeitoFancy
Estudo de caso: investigação do "Efeito Fancy". Análise de dados unificando bases de CRM, ERP e E-commerce com Python/Pandas. Inclui feature engineering (Margem Bruta, Ticket Médio e Fancy Score), código, datasets CSV e dashboard interativo para análise do perfil de clientes e direcionamento de campanhas de marketing.
